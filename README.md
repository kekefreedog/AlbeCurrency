# AlbeCurrency

Pocket helper for paying in Lebanon with mixed **USD / LBP** cash: enter the
receipt total, tap the bills you hand over (or receive), and the app checks the
change against the current rate and suggests the bills to expect back. The
history is kept on the device.

One web UI, three targets:

| Target | Shell | Business logic | Storage |
|---|---|---|---|
| Web / PWA | browser | `albe-core` compiled to WebAssembly (`albe-wasm`) | IndexedDB |
| Desktop (macOS, Windows, Linux) | Tauri 2 | `albe-core` native, behind Tauri commands | SQLite |
| Android / iOS | Tauri 2 mobile | same as desktop | SQLite |

The backend is picked at runtime in `src/backend/index.ts`: `TauriBackend`
inside Tauri, `WasmBackend` in a plain browser.

## Layout

```
crates/
  albe-core/     Pure Rust logic: money, rates, change check, bills, receipt parsing (+ tests)
  albe-wasm/     wasm-bindgen bindings of albe-core for the web build
src-tauri/       Tauri app (albe-app): commands, SQLite store, capabilities, icons
src/             TypeScript UI (Materialize): pages, components, services, backends
  wasm/pkg/      Generated by `npm run wasm` (git-ignored)
public/          Static assets, banknote images (see public/bills/CREDITS.md)
```

## Requirements

- Node.js 20+ and npm
- Rust (rustup) with the `wasm32-unknown-unknown` target
- `wasm-bindgen-cli` matching the crate version (`=0.2.129`):
  `cargo install wasm-bindgen-cli --version 0.2.129`

If `cargo` is not found, add `~/.cargo/bin` to your `PATH`
(`source "$HOME/.cargo/env"`).

## Getting started

```sh
npm install
npm run wasm        # build albe-wasm into src/wasm/pkg (needed before dev/build)
npm run dev         # web UI on http://localhost:5173 (WASM backend)
npm test            # cargo test --workspace
npm run build       # wasm + type check + production bundle in dist/
```

Desktop app:

```sh
npm run tauri dev
npm run tauri build
```

## Continuing the mobile build (Android / iOS)

The Rust side is already mobile-ready (`crate-type = ["staticlib", "cdylib",
"rlib"]`, `tauri-plugin-haptics` for Android/iOS, Vite reads `TAURI_DEV_HOST`
for devices). What remains is setting up the toolchains and generating the
native projects under `src-tauri/gen/`.

Already installed on the dev machine (2026-10-17): Rust targets
`aarch64-linux-android`, `armv7-linux-androideabi`, `x86_64-linux-android`,
`aarch64-apple-ios`, `aarch64-apple-ios-sim`; Android SDK in
`~/Library/Android/sdk`; Xcode.

### Android

1. **Install the NDK** (missing): Android Studio → Settings → Languages &
   Frameworks → Android SDK → SDK Tools → check *NDK (Side by side)* and
   *Android SDK Command-line Tools*.
2. **Environment** (add to `~/.zshrc`):

   ```sh
   export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
   export ANDROID_HOME="$HOME/Library/Android/sdk"
   export NDK_HOME="$ANDROID_HOME/ndk/$(ls -1 $ANDROID_HOME/ndk | sort -V | tail -1)"
   export PATH="$HOME/.cargo/bin:$PATH"
   ```

3. **Missing Rust target** (32-bit x86 emulators only, optional):
   `rustup target add i686-linux-android`
4. **Generate the project**: `npm run tauri android init`
   (creates `src-tauri/gen/android`, commit it).
5. **Run**: start an emulator (or plug a phone with USB debugging), then
   `npm run tauri android dev`.
   For a physical device Tauri sets `TAURI_DEV_HOST`; phone and Mac must be on
   the same network.
6. **Release build**: `npm run tauri android build -- --apk` (or `--aab` for
   the Play Store). Sign it: create a keystore with `keytool`, then configure
   `src-tauri/gen/android/app/build.gradle.kts` with a `signingConfigs` block
   reading a git-ignored `keystore.properties`
   (see https://v2.tauri.app/distribute/sign/android/).

### iOS

1. **Xcode**: open it once to accept the license and install the iOS
   platform/simulator (Xcode → Settings → Components).
2. **CocoaPods** (missing): `brew install cocoapods`
3. **Generate the project**: `npm run tauri ios init`
   (creates `src-tauri/gen/apple`, commit it).
4. **Signing**: set your Apple team, either in Xcode
   (`src-tauri/gen/apple/*.xcodeproj` → Signing & Capabilities) or with
   `export APPLE_DEVELOPMENT_TEAM=<TEAM_ID>` before `init`. A free Apple ID
   works for running on your own phone; App Store / TestFlight needs the paid
   developer program.
5. **Run**: `npm run tauri ios dev` (simulator) or
   `npm run tauri ios dev -- --open` to pick a device in Xcode.
6. **Release build**: `npm run tauri ios build`, then upload the `.ipa` with
   Xcode Organizer or Transporter.

### Mobile checklist

- [ ] App icons: `npm run tauri icon path/to/icon-1024.png` regenerates desktop,
      Android and iOS icons (run after `init` so the mobile folders exist).
- [ ] Bundle identifier `com.kekefreedog.albecurrency` (in
      `src-tauri/tauri.conf.json`) must be final before publishing; it cannot
      change after release on either store.
- [ ] Camera access for receipt scanning: add the OCR/camera plugin, its
      permission in `src-tauri/capabilities/mobile.json`, `NSCameraUsageDescription`
      in `src-tauri/gen/apple/*/Info.plist` and the `CAMERA` permission in
      `src-tauri/gen/android/app/src/main/AndroidManifest.xml`.
- [ ] Check the CSP in `tauri.conf.json` still allows the rate APIs
      (`open.er-api.com`, `cdn.jsdelivr.net`) on device.
- [ ] Test haptics on a real device (no effect in simulators).
- [ ] Confirm the LBP banknote image licenses before a store release.
